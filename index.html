Agentra – Adaptive Multi-Agent AI Platform

An adaptive multi-agent AI platform that decomposes complex tasks into DAG-based subtasks and dynamically assigns optimal LLMs for execution.

Multi-Agent AI LangChain DAG Decomposition
Live Demo ↗ GitHub ↗

Agentra is an intelligent multi-agent platform designed to decompose complex natural language queries into hierarchical, DAG-structured subtasks and route each subtask dynamically to optimal LLMs. Implements shared memory, trust-based escalation, and specialized AI agents for research, RAG retrieval, code generation, and multimodal analysis.

DAG-Based Recursive task decomposition & parallel execution graph
Shared Memory Redis state cache + persistent cross-agent context
Multi-Domain Specialized agents for Research, RAG, Code & Multimodal
